# Security Policy

## Supported Version

Only the current production release from the protected `main` branch receives
security fixes. Older commits and local development builds are unsupported.

## Reporting A Vulnerability

Use this repository's **Security** tab and select **Report a vulnerability** to
open a private GitHub security advisory. Do not disclose a suspected
vulnerability in a public issue, discussion, or pull request.

We aim to acknowledge a report within three business days and provide an
initial assessment within seven business days. Remediation and disclosure
timelines depend on severity, exploitability, and deployment risk. Please allow
time for a coordinated fix and production verification before disclosure.
